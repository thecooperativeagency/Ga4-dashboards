Core four search pressure

Google search demand for BMW, Mercedes-Benz, Lexus, and Audi — brand name plus each brand’s top five model keywords — in the Baton Rouge DMA and New Orleans DMA.
Keyword Planner · Google Search · English · data pull 2026-07-30 · average monthly search estimates
How to read the numbers. Each figure is Google Keyword Planner’s average monthly searches for an exact keyword in that market. These are estimated bands (not exact unique people).

Brand-root = head term only (bmw, mercedes benz, lexus, audi).
Top 5 models = the five highest model keywords we measured for that brand.
Total search pressure = brand-root + top 5 models. Useful planning total; keywords can overlap (someone may search both bmw and bmw x5), so this is not a count of unique shoppers.
